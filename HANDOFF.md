# Starty landing page — context handoff

Date: 2026-09-16 (updated later the same day: new hero UI + brand-brief copy pass). Project: `/Users/hamzajamal/Documents/Claude Projects/starty` (Next.js 15, App Router, TypeScript). Owner: Hamza Jamal (hamza.jamal@imagine.art).

## What this is

A Starty marketing landing page. It started as a pixel-faithful port of viktor.com (saved as "Web page, complete" in `../replica`), was rebranded to Starty, had the ImagineArt landing-page kit applied on top, and then had its copy repositioned from the Q4 2026 brand brief (`~/Downloads/Starty-Marketing-Brand-Strategy-Q4-2026.pdf`): **Starty is the AI consumer app builder** for creators, non-technical founders and product designers. Build (agents, models, templates, the builder) · Run (compute, data, security, auth, payments) · Grow (messaging, referrals, paid growth). The page is a single route at `/`.

## Run

```bash
cd starty
npm install
npm run dev        # http://localhost:3000  (predev regenerates the footer CSS)
npm run build      # prebuild does the same
```

If the ported markup, the colour map, the wording rules, or the hero snippets change, regenerate with:

```bash
python3 scripts/port.py
```

That script also runs `scripts/brand.py`. The PNG recolour step inside it needs Pillow from the local venv: `scripts/.venv/bin/python` (create with `python3 -m venv scripts/.venv && scripts/.venv/bin/pip install pillow`).

## Architecture in one paragraph

The page body is static HTML in `app/body.html`, generated by `scripts/port.py` from the saved viktor.com export and rendered by `app/page.tsx` with `dangerouslySetInnerHTML`. React owns three things around it: `components/SiteNav.tsx` (kit navbar), `components/SiteFooter.tsx` (kit footer), and `app/interactive.tsx` (a client component that restores behaviour on the static markup). Styling is the site's original compiled Tailwind stylesheets in `public/css/` plus one hand-written override file, `public/brand.css`, which holds everything Starty-specific. This project does not run Tailwind for the page itself.

## Brand decisions (confirmed by the owner)

- Palette from the owner's SVG: blue `#0088FF`, deep blue `#0049A0`, pink `#F0ABD5`, orange `#FA8E59`. Purple originals map to these; lavender tints map to pink.
- Tagline: "Build. Work. Grow." with "Meet Starty." as the accent line (`retagline` in brand.py).
- Heading accent colour stays **Starty blue** even though the kit is monochrome. Owner explicitly asked for this.
- Typeface: **Google Sans Flex everywhere, headings included** (kit rule). Only the "Starty" wordmark in nav/footer still uses UlmGrotesk as a logo mark.
- Body/subcopy weight 400; headings weight 500; nothing above 600 except the Slack-mockup sender names, which imitate Slack.
- Kit type scale applied: h1 `clamp(34px,4.4vw,54px)`, section h2 `clamp(28px,3.6vw,44px)`, FAQ h2 `clamp(36px,4vw,52px)`, closing CTA `clamp(32px,4.4vw,56px)`, card h3 `clamp(19px,1.5vw,22px)`, intros 17px/1.7 `rgb(87,87,87)`, card body 14.5px/1.65 `rgb(100,100,100)`, headings `#171717`, eyebrows mono 11px/600/uppercase.
- Container: 1240px max, 32px gutters (20px under 768px), applied via attribute selectors in brand.css.
- Section guide lines were tried and **removed** at the owner's request.
- Footer: the kit's `SiteFooter.tsx` **verbatim** (ImagineArt columns, Vyro copyright) except the big ImagineArt watermark, which was removed on request.
- Navbar: the kit's `SiteNav.tsx` adapted (Starty wordmark, links: How It Works, Features, Compare, Security, FAQ, Pricing).
- Hero: headline + subcopy, then the demo-video placeholder. The two CTA buttons were removed at the owner's request (`drop_hero_ctas` in brand.py). The earlier prompt box / chips / app-UI versions are gone.
- Copy: repositioned to the brand brief across every section (hero, rotating band, workspace, features = Build/Run/Grow cards, compare, how it works, security guardrails, testimonials, FAQ, closing CTA "Go outside. We will run the app."). Slack mockups kept as visuals; their text was left where it already fit the Run story. Testimonial names/photos are the ported placeholders; the quotes were reworded to the app-builder story.
- **Work vs Run:** the brief's pillars are Build / **Run** / Grow, but the confirmed tagline says Build / **Work** / Grow. Left as "Work". Owner to decide.
- Hero background: the compiled stylesheet's `--gradient-home-hero-light` (an SVG radial gradient) is overridden in brand.css with a smoother ramp (beige → peach → pink → lavender → blue → deep blue) because the original jumped from pink straight to sky blue. Same geometry and endpoints.
- Closing CTA: deep blue band ending in a smooth glow (three layered radial gradients: orange, pink, blue) fading into the footer's `#070707`.
- All former viktor.com / app.viktor.com / G2 links point to `#`. Only three LinkedIn profile links on testimonials remain external.

- Demo video not yet supplied. To wire it: put the file (and a poster frame) in `public/media/`, uncomment the `<video>` in `scripts/hero-app.html`, delete the placeholder div, run `python3 scripts/port.py`.
- The dark-band headline still auto-rotates; the kit forbids decorative motion. Not yet changed.
- Footer content is ImagineArt's (columns, app badges, socials, Vyro copyright) because the owner asked for it verbatim. Revisit if Starty-specific footer content is wanted.
- Dev-only React hydration warning on the injected body markup is suppressed with `suppressHydrationWarning`; harmless.
- `next build` and `next dev` share `.next`; don't run a build while the dev server is up.
